# BotBuild

Приложение, позволяющее создавать ботов для автоматизации из блоков действий, используя визуальный нод-редактор.

---

### Технологии:

- pyside6
- pillow
- numpy
- opencv-python
- pyautogui

### Требования:

Python версии 3.13

### Установка:

1. Клонируйте репозиторий:
   `git clone https://github.com/MrFreemanes/BotBuild.git`
   и зайдите в созданную папку.
2. Создайте виртуальное окружение Python командой:
   `python -m venv .venv`
   или в IDE.
3. Активируйте окружение:
   `venv\Scripts\activate`
4. Установите зависимости: `pip install -r requirements.txt`

---

## Возможности:

- Использование нод в качестве действия (например нажатие или поиск изображения) и их связь через порты.
- Подсветка работающего в данный момент действия.
- Сохранение и загрузка графа.
- Ноды:
    1. If позволяет в зависимости от результата действия выбрать следующее.
    2. WaitUntil позволяет зациклить одно действие в ожидании положительного результата или определить timeout.
    3. Wait останавливает работу на указанное время.
    4. Click выбор нажимаемой кнопки и количества нажатий по координатам найденного изображения.
    5. Search позволяет выбрать шаблон для поиска и подключить его к If или WaitUntil.

---

## Как создать своего бота:

1. Переместить из боковой панели нужные действия на граф.
2. Выбрать шаблоны поиска в Search.
3. Выстроить логическую цепочку с помощью связей портов нод.
